# Healthcare Data Analysis 🏥

## About the Project

This project is about exploring healthcare data to understand patient trends and find useful insights. I worked on this project to learn how data analysis can help make healthcare information easier to understand.

## Tools Used

- Power BI
- Microsoft Excel

## What I Worked On

- Explored patient data to understand different trends.
- Analyzed patient demographics and disease patterns.
- Studied treatment-related information available in the dataset.
- Created interactive dashboards to present key healthcare insights.

## Key Learnings

While working on this project, I learned how to organize and analyze data, create meaningful visualizations, and present information through an interactive dashboard. It also helped me improve my Power BI skills and understand how data can support better decision-making.

## Dashboard

I used Power BI to create a dashboard that presents important healthcare information in a simple and visual format.

## Skills Used

Power BI | Excel | Data Analysis | Data Visualization | Dashboard Development

## Conclusion

This project gave me an opportunity to practice my data analysis skills using real-world-style healthcare data. I enjoyed exploring the data, identifying patterns, and presenting my findings in a clear and simple way.
